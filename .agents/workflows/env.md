# /env — 环境与密钥协议

当用户输入 `/env` 时，执行以下步骤：

// turbo-all

## 步骤

1. 读取密钥总控台（索引网关）
```
view_file /path/to/记忆系统/秘钥文档/00_密钥总控台_Registry.md
```

2. 根据用户的后续指令判断场景：
   - **需要密钥** → 从「密钥总控台」快速检索表定位密钥文件 → 读取实际值
   - **记录新密钥** → 更新对应密钥文件 + 更新「密钥总控台」矩阵表
   - **配置 .env** → 参考「密钥总控台」的 .env 模板快照
   - **推送代码** → 参考项目映射表，执行 git 推送
   - **部署环境变量** → 用云平台 CLI 设置

3. 汇报已加载的信息，等待用户指令。
